# project-D-D — Tabletop

เว็บโต๊ะเล่นเกมเล่าเรื่อง (แนว D&D 5e) สำหรับเล่นกับเพื่อนผ่าน browser ไม่ต้องใช้กระดาษ
ตัวละครสำเร็จรูป 2 เซ็ต — ฮีโร่ชุดแรก 10 ตัว + วีรชนในตำนาน 12 ตัว (เลือด, ความแข็งแกร่ง, ความทนทาน, ความว่องไว, มานา + สกิลใช้มานา) ให้ผู้เล่นเลือกคนละใบ — DM เลือกเซ็ตที่ใช้เล่นและแก้ roster ได้ในแอป

**เวอร์ชัน:** 0.17.1 · **สถานะ:** เล่นได้บนเครื่องตัวเอง + เพื่อนใน Wi-Fi เดียวกัน — เมนูแคมเปญ, lobby, ตัวแก้ roster, เลือกตัวละคร 10 คลาส + สกิลมานา + feed, แมพ + grid + token + fog, โน้ตเนื้อเรื่อง + NPC Pool ของ DM, TUI launcher, หน้าตาโทน medieval, QR เข้านั่ง, TUI dashboard + reload

---

## 1. ติดตั้งครั้งแรก
ต้องมี **Go 1.26+** และ **Node 24+**
```sh
git clone <repo> && cd project-D-D
cd web && npm install && cd ..
```

## 2. วิธีรัน
| คำสั่ง | ใช้เมื่อ | เปิดที่ |
|---|---|---|
| `make run` | **เล่นจริง** — เปิด TUI: หน้ายินดีต้อนรับ → กดปุ่มเริ่ม → ดู log สด | http://127.0.0.1:8080 (เครื่องเรา) · ลิงก์ LAN ขึ้นใน TUI |
| `make dev` | **พัฒนา** — Go server + Vite (แก้หน้าเว็บแล้วรีเฟรชเอง) | http://localhost:5173 |
| `make build` | สร้าง binary: `bin/tabletop` (TUI) + `bin/dnd` (server เปล่า ไม่มี TUI) | — |
| `./bin/tabletop` | รัน TUI จาก binary ที่ build แล้ว | http://127.0.0.1:8080 |
| `./bin/dnd` | รัน server แบบไม่มี TUI (log ออก terminal) | http://127.0.0.1:8080 |

**ค่าเริ่มต้นเปิดให้ Wi-Fi เดียวกันเข้าได้** (`-addr 0.0.0.0:8080`): เพื่อนเปิดลิงก์ LAN ที่ TUI แสดง หรือสแกน QR จาก DM

> ⚠️ **ความปลอดภัย:** ห้องไม่มีรหัสผ่าน ใครอยู่ Wi-Fi เดียวกันก็เปิดหน้าเว็บได้ กดเป็น DM ได้ถ้ากดก่อน และนั่งเก้าอี้ว่างได้
> ใช้ Wi-Fi สาธารณะ (ร้านกาแฟ ฯลฯ) ให้รัน `./bin/tabletop -addr 127.0.0.1:8080` (เครื่องเราเท่านั้น) · macOS อาจถามเรื่อง firewall ครั้งแรก ให้กด Allow

## 3. วิธีเล่น
1. **DM** เปิดเว็บ → ใส่ชื่อ → เลือกแคมเปญ **Starter Set** (Salem = "Coming soon") → คนที่เลือกคือ DM
2. **Lobby** — DM กด **+ เก้าอี้ผู้เล่น** (สูงสุด 6 คน) / เปิดที่ DM ร่วม; เพื่อนเปิดลิงก์เดียวกัน → เลือกเก้าอี้ → ใส่ชื่อ → กด **พร้อม / Ready**
   - **เซ็ตตัวละคร:** DM/co-DM ติ๊กเลือกเซ็ตที่ใช้เล่นได้หลายเซ็ต (ฮีโร่ชุดแรก / วีรชนในตำนาน, ต้องเปิดอย่างน้อย 1) — เปลี่ยนได้เฉพาะก่อนกดเริ่ม ผู้เล่นเห็นชื่อเซ็ตที่เปิด
   - **QR:** DM กด **QR / สแกนเข้านั่ง** ที่เก้าอี้ว่าง → QR ขึ้นกลางจอพร้อม "ที่นั่ง N" → เพื่อนสแกนด้วยกล้องมือถือ → ใส่ชื่อ → กด **นั่ง / Sit**
3. (ถ้าต้องการ) DM เปิด **ชุดกฎ / Ruleset** = ตัวแก้ roster: แก้ชื่อ/รูป/stat/สกิล/ของเริ่มต้น แยกแท็บตามเซ็ต, **รีเซ็ตตัวนี้ / รีเซ็ตเซ็ตนี้** · เก็บถาวรใน `data/roster.json` · มีผลกับตัวที่ถูกเลือกหลังแก้
4. DM กด **เริ่มเกม / Start** (กดได้เมื่อทุกคนที่นั่งพร้อมแล้ว)
5. **เลือกตัวละคร** — ผู้เล่นเลื่อนการ์ดของเซ็ตที่เปิด (เปิด 2 เซ็ต = 22 ใบ มีป้ายชื่อเซ็ต) (ปัด, ปุ่ม ‹ ›, คีย์ ←/→) → กด **เลือกตัวนี้** (ห้ามซ้ำ: ใบที่คนอื่นเลือกแล้วจะเทา · คลาสเดียวกันจากคนละเซ็ตเลือกพร้อมกันได้)
   → เพิ่ม **สกิลของฉัน** ได้อีก 3 อัน (ข้ามได้) · ทุกคนเลือกครบ = เข้าแมพ · DM ไม่เห็นหน้าเลือก แต่เห็นการ์ดเต็มใบของผู้เล่นแต่ละคนเป็น grid (ตัวที่เลือก หรือ "กำลังเลือก…")
6. **แมพ** — จอแบ่งสองฝั่ง: แมพซ้าย ข้อมูลขวา (ลากแถบตรงกลางเพื่อปรับขนาด, มือถือ = แมพบน ข้อมูลล่าง) · แมพพอดีกรอบเสมอ ไม่ต้องเลื่อน
   - DM อัปรูปแมพ → กด **−/+** ปรับจำนวนคอลัมน์กริด (ช่องจัตุรัส คลุมทั้งรูป) → บันทึก → เลือกฉาก (ทุกคนย้ายไปฉากนั้น)
   - ผู้เล่น: **จิ้ม/คลิกช่องปลายทาง** แล้วตัวละครเดินไปเลย
   - ผู้เล่น: ชีทตัวเอง (HP, มานา, stat, สกิล, ของ) → กด **ใช้** สกิล = หักมานาเอง (มานาไม่พอกดไม่ได้) · ทุกคนเห็นแผง **บันทึก / Feed**
   - DM: แถบ **ปาร์ตี้** (รูปกลมทุกตัว) → คลิก = **การ์ดโปรไฟล์** มุมขวาล่าง: HP/มานา −/+, แก้ stat, ให้ของ, ลบของ · ปุ่ม **พักผ่อน** = มานาเต็มทุกคน
   - DM: จิ้ม token เพื่อเลือก → จิ้มช่องปลายทาง, โหมด fog (ลากสี่เหลี่ยม = ซ่อน, คลิก = เปิด)
   - **NPC Pool** (เมนู DM): กด **+ เพิ่ม NPC** → รูป, ชื่อ, ปกปิด, เลือด → **วางบนแมพ** (วางซ้ำได้) · ในรายการ token: ซ่อน/เปิดเผย, HP −/+ · NPC ที่ซ่อน ผู้เล่นมองไม่เห็นเลย, HP ของ NPC เห็นแค่ DM · pool เก็บถาวรใน `data/npcs.json`
     - ชื่อใน pool ห้ามซ้ำ · token ในฉากเดียวกันไม่ซ้ำ: `Goblin`, `Goblin #2`, … (เลขถัดไป = เลขสูงสุด + 1) · ปุ่ม **เพิ่มอีกตัว / Duplicate** ที่แถว token NPC = ตัวใหม่ HP เต็ม ช่องว่างใกล้สุด
7. เมนู DM เปิดได้หลายหัวข้อพร้อมกัน (เช่น ฉาก + หมอก) และจำไว้หลังรีเฟรช
8. **โน้ตเนื้อเรื่อง (DM)** — เมนู DM → **เนื้อเรื่อง**: เพิ่มโน้ตได้หลายอัน คลิกชื่อโน้ตแล้วเนื้อหากางลงมาในแผงเลย (เขียนแบบ markdown ได้: `# หัวข้อ`, `**ตัวหนา**`, `*เอียง*`, `- รายการ`, `> คำพูด`) ระหว่างอ่านยังเล่นได้ตามปกติ · ปุ่ม **แก้ไข** แก้ในที่เดิม บันทึกอัตโนมัติ เก็บถาวรใน `data/notes.json` (ผู้เล่นไม่เห็น) · เปิดได้ตั้งแต่ lobby
   - **โหมดต่อสู้**: DM กด "โหมดต่อสู้" → ผู้เล่นกด **โจมตี** → จิ้มเป้าบนแมพ (หรือเลือกจากรายการ) → ทอยลูกเต๋าจริง → DM กด **โดน/ไม่โดน** (+ดาเมจ หัก HP อัตโนมัติ) → ทุกคนเห็นป้าย "โดน!"/"ไม่โดน!" กลางจอ
     - **NPC action** (DM, ระหว่างโหมดต่อสู้): จิ้ม NPC/มอนสเตอร์บนแมพ → จิ้มตัวละครผู้เล่น (หรือปุ่ม **Action** ในรายการ token) → เลือก **คุย** (พิมพ์คำพูดได้) / **โจมตี** (โดน/ไม่โดน + ดาเมจ หัก HP อัตโนมัติ) / **มอบของ** (เข้ากระเป๋าจริง) / **ยอมแพ้** → ป้ายใหญ่ทุกจอ + บันทึกการเล่น · NPC ที่ซ่อนอยู่ต้องเปิดเผยก่อน
   - **บันทึกการเล่น** (ล่างสุดของแถบข้อมูล): ผู้เล่นเห็นบันทึกสาธารณะ · DM เห็นบันทึกเต็ม ใครทำอะไร — เข้า/ออก, ย้าย, สกิล, โจมตี, ดาเมจ, ตาย 💀/ฟื้น, ของ, NPC ฯลฯ (DM เท่านั้น, ล่าสุด 300 บรรทัด)
9. **ทอยเต๋า** — ใช้**ลูกเต๋าจริง** ทอยที่โต๊ะ/หน้ากล้อง แล้วบอกผลใน Discord (แอปไม่มีระบบทอยเต๋า)

เสียงคุยใช้ Discord · แมพ/เนื้อเรื่อง Starter Set ต้องมาจากของที่ DM มีเอง (แอปไม่รวมเนื้อหาลิขสิทธิ์) — ดู `docs/campaigns/starter-set/README.md`

## 4. ทดสอบ
```sh
make test                    # Go unit tests (rules, ห้อง/สิทธิ์, upload, server, TUI)
cd web && npm run test:e2e   # Playwright: DM + ผู้เล่น เล่นครบ flow (build + รัน bin/dnd ที่ port 18080 เอง)
cd web && npm run build      # ตรวจ type + build หน้าเว็บ
```

## 5. ปัญหาที่เจอบ่อย
| อาการ | สาเหตุ / วิธีแก้ |
|---|---|
| สแกน QR แล้วมือถือเข้าไม่ได้ | มือถือต้องอยู่ Wi-Fi เดียวกับเครื่อง · ถ้า QR ขึ้นคำเตือน = server รันแบบ 127.0.0.1 → รันใหม่ด้วย `-addr 0.0.0.0:8080` · มีหลาย IP ให้กดเลือกที่อยู่อื่นในหน้าต่าง QR |
| TUI ขึ้น error ตอนกดเริ่ม | port 8080 ถูกใช้อยู่ → ปิดโปรแกรมนั้น หรือรัน `./bin/tabletop -addr 127.0.0.1:8081` |
| ปิด server แล้วเกมหาย | ตั้งใจ: v0 เก็บ state ใน memory · รูปที่อัปยังอยู่ใน `uploads/` |
| รีเฟรชหน้าแล้วกลับมาเก้าอี้เดิม | ตั้งใจ: browser จำ id ไว้ (เปิดหน้าต่างส่วนตัว = คนใหม่) |
| `make build` error เรื่อง embed | รัน `cd web && npm install` ก่อน แล้ว `make build` ใหม่ |
| อัปรูปไม่ได้ | ต้องนั่งเก้าอี้ก่อน, ไฟล์ ≤ 10MB, png/jpeg/gif/webp เท่านั้น |
