## สิ่งที่ผู้ใช้ยืนยันแล้ว
- ฉาก: เมือง Salem · เนื้อเรื่อง: ล่าแม่มด · อ้างอิงเกมกระดาน **Salem 1692** (Facade Games)
- แม่มด 1 ตัวเป็น **NPC** ที่ DM เล่น; ผู้เล่นรู้ว่ามี แต่ไม่รู้ว่าใคร; แม่มดปลอมตัวเป็นชาวเมือง
- ปรับให้เข้ากับ D&D style ได้

## ข้อกำหนดเรื่องลิขสิทธิ์ + ความละเอียดอ่อน
- ชื่อแคมเปญ **ห้ามใช้ "Salem 1692"** → ตั้งชื่อใหม่ (รอผู้ใช้เลือก)
- ห้ามใช้คำของเกม ("Tryal", "Town Crier", "frame card") → ใช้ Secrets / Suspicion / Hearing / Night Watch แทน
- หมู่บ้านสมมติ "ได้แรงบันดาลใจจาก 1692"; NPC ชื่อสมมติทั้งหมด; ห้ามให้บุคคลจริงเป็นแม่มด
- แม่มด = **hag** สิ่งเหนือธรรมชาติที่สวมรอยชาวบ้าน → ความชั่วร้ายจริงคือ "ความตื่นตระหนก" ที่ผู้เล่นต้องต้านไว้

## แนวคิดหลัก
ผู้เล่นเป็นนักสืบ/นักล่าแม่มด เก็บเบาะแสกับ NPC แต่ละตัว จนพอจะเปิดโปงแม่มดได้ ขณะที่ทุกคืนแม่มดลงมือ และความตื่นตระหนกในเมืองก็สูงขึ้นเรื่อย ๆ — ถ้าประณามผิดคน เมืองจะพังเอง

### ทอยสกิล (ชื่อสกิลจาก SRD; DC เป็นข้อเสนอ)
| สกิล | ใช้ทำอะไร |
|---|---|
| Insight | จับโกหก (Mimicry ของ Green Hag จับได้ด้วย Insight DC 14) |
| Investigation | หาหลักฐาน (+3) |
| Perception | เฝ้ายามกลางคืน |
| Medicine | แยกอาการจริงกับแกล้งชัก |
| Religion | รู้วิธีกันแม่มดจริงกับความเชื่อผิด ๆ |
| History | โฉนดที่ดิน, แรงจูงใจความบาดหมาง |
| Persuasion / Deception / Intimidation | ขอคำให้การ (= action Influence ใน SRD, DC ปกติ 15) |

DC แนะนำ: ข่าวลือ 10 · หลักฐาน 15 · ทำลายคำโกหก 20

### Hearing (การไต่สวน)
- ผู้พิพากษา NPC เป็นประธาน; ทีมเถียงร่วมกัน **3 รอบ** แต่ละรอบผู้เล่นทอยสกิลที่เกี่ยวข้อง 1 ครั้ง; เบาะแสจริงแต่ละชิ้นที่ยกมา +2
- ชนะ 2 ใน 3 รอบ → ผู้ถูกกล่าวหาถูกขัง + เปิด Secret 1 ใบ; ถ้าเป็น **The Mark** → แม่มดถูกเปิดโปง เข้าฉากจบ
- แพ้ → ปล่อยตัว + **Dread** +1

### Dread (ความตื่นตระหนกของเมือง) 0–10
- +1 ทุกคืนที่มีคนตาย · +2 ทุกครั้งที่ประณามคนบริสุทธิ์ · −1 เมื่อแชร์เบาะแสจริงต่อสาธารณะ
- ถึง 5 → ฝูงชนลุกฮือ Night clock เร็วขึ้น · ถึง 10 → เมืองล่ม

### แพ้ / ชนะ
- **แพ้**: Dread ถึง 10 · ประณามผู้บริสุทธิ์ 3 คน · แม่มดรอด 7 คืน · ทีมตายหมด
- **ชนะ**: เปิด The Mark แล้วสู้ชนะหรือไล่แม่มดออกไปในฉากจบที่ป่า (เหมือนเกม: เปิดโปงคือชนะ ไม่ต้องฆ่า)

### ความยาว
~4 session × ~3 ชม.: (1) มาถึง เด็กมีอาการ คืนแรก · (2–3) สืบ + Hearing, Conspiracy กลางเรื่อง · (4) เปิดโปง + เผชิญหน้า · เพิ่ม session 5 ถ้าทีมติด

## Ruleset preset "Salem" (ข้อเสนอ — สำหรับระบบ white label)
- **Stat**: 6 ability ของ SRD (STR, DEX, CON, INT, WIS, CHA) + **HP** + **Faith** 0–5 (ใช้ 1 แต้มทอย save ต้านเวทแม่มดใหม่ หรือกันบ้านได้ 1 คืน; ฟื้นตอนประชุมวันสะบาโต) + **Nerve** 0–5 (เห็นสิ่งน่ากลัว −1; ถึง 0 = Frightened จนพัก)
  - ไม่ใช้ชื่อ "Sanity": ไม่อยู่ใน SRD และตีตราโรคทางจิต
  - Suspicion และ Dread เป็นของ NPC/เมือง **ไม่ใช่** stat ผู้เล่น
- **Skill** 12 จาก 18 ของ SRD: Insight, Investigation, Perception, Persuasion, Deception, Intimidation, Religion, History, Medicine, Survival, Stealth, Athletics · เลือก 4
- **ไอเทมเริ่มต้นทุกคน**: คัมภีร์/หนังสือสวด, ตะเกียงมีฝา, ชุดจุดไฟ, เชือก, มีดพก, สมุด + ปากกาขนนก + หมึก, 5 shilling
- **เลือก 1**: ปืนคาบศิลา (SRD: Pistol 1d10 / Musket 1d12) · ชุดปฐมพยาบาล · กุญแจมือ + หมายศาล · เกลือ + ตะปูเหล็ก (เครื่องกันแม่มดพื้นบ้าน — เราคิดเอง)
- ไม่ใส่น้ำมนต์: มีใน SRD แต่ชาว Puritan ไม่ใช้
