# แคมเปญ: Salem (ล่าแม่มด)

**สถานะ:** โครงร่าง รอคำตอบเรื่องที่มา ("Salem1982") ก่อนเขียนเนื้อเรื่อง
ที่มา: [`../../conversations/2026-10-16-web-flow.md`](../../conversations/2026-10-16-web-flow.md)

## สิ่งที่ผู้ใช้กำหนด
- ฉาก: เมือง Salem
- เนื้อเรื่อง: การล่าแม่มด
- แม่มด 1 ตัว เป็น **NPC** (DM เล่น) ไม่ใช่ผู้เล่น
- เอา Salem มาประยุกต์เข้ากับ D&D

## ข้อมูลพื้นหลังที่อาจเกี่ยวข้อง (ยังไม่ได้ research — ห้ามถือเป็นข้อเท็จจริง)
- เหตุการณ์จริง: การไต่สวนแม่มดที่ Salem รัฐแมสซาชูเซตส์ ปี **1692** (ประวัติศาสตร์ ใช้เป็นแรงบันดาลใจได้)
- เกมกระดาน **"Salem 1692"** (Facade Games) — เกม social deduction ที่ผู้เล่นบางคนเป็นแม่มดลับ (มีลิขสิทธิ์ ยืมแนวคิดได้ ห้าม copy การ์ด/ข้อความ)
- "Salem 1982" อาจหมายถึงอย่างอื่น → ถามผู้ใช้แล้ว
