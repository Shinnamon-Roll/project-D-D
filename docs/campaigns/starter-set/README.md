- [ ] ห้อง Discord สำหรับคุยเสียง

## ตัวละครสำเร็จรูป → ใส่ในแอป
เลือกได้ 2 ทาง (รอผู้ใช้เลือก — Q20):
- **ก. เล่นตามชีท 2014 ตรง ๆ** (แนะนำ ง่ายสุด): ruleset = preset D&D 5e แล้วผู้เล่นกรอกตัวเลขจากชีทลงตอนสร้างตัวละคร (DM แก้ stat ให้ได้)
- ข. แปลงเป็นกฎ 2024: เผ่า/background ใหม่; Folk Hero (Fighter) และ Noble (Paladin) ไม่มีใน SRD ต้องหาตัวแทน

| ตัว | Class / เผ่า / Background |
|---|---|
| 1 | Cleric · Hill Dwarf · Soldier (Life Domain) |
| 2 | Fighter · Wood Elf · Folk Hero (Archery → Champion) |
| 3 | Paladin · Human · Noble (Protection, สาบานต่อ Bahamut) |
| 4 | Rogue · Lightfoot Halfling · Criminal (→ Thief) |
| 5 | Wizard · High Elf · Sage (Evocation) |
