# 2026-10-16 — ตัวละครสำเร็จรูป 10 คลาส (การ์ดเลื่อนเลือก)

## คำขอ (คำต่อคำ)
> ในหน้า build character change skill and stat menu to character menu. We will fix 10 character for 10 class and แต่ละคลาสจะมี สกิลและ สแตทที่แตกต่างกัน สแตทหลักๆที่ควรจะมี เลือด, ความแข็งแกร่ง ความทนทาน ความว่องไว มานา สกิลถ้าจะใช้สกิล จะต้องเสียมานา แต่ละตัวละคร จะมีของติดตัวไม่เหมือนกัน เน้นความหลากหลายเป็นหลัก ui จะเป้นการ์ด เลือนซ้ายขวาเพื่อเลือกตัวละคร ไปหารูปมาใส่ได้เลย SVG ก็ได้ หามาก่อน เอาให้ตรง character นะเพื่อน ตั้งชื่อตั้งอะไรได้เลย ใน motion ด้วยนะตอนเลื่อนจะได้สวยๆหน่อย
