# 2026-10-16 — ออกแบบหน้าตาเว็บใหม่ โทน medieval

## คำขอ (คำต่อคำ)
> หน้าUI แม่งอยากกาก ให้ ใช้ /ui-ux-pro-max:design  ดีไซน์หน้าตาออกมาหน่อย เจนรูปได้ ใช้สีโทน medieval

## สรุป
- ผู้ใช้ไม่ชอบหน้าตาเดิม (system font, ขาว/เทา) → ขอออกแบบใหม่ โทนยุคกลาง (medieval) และให้เจนรูปประกอบได้
- เครื่องนี้ไม่มี `GEMINI_API_KEY` / `MUAPI_API_KEY` → เจนรูปแบบ raster ด้วย AI ไม่ได้ตอนนี้
  → ทำภาพประกอบเป็น **SVG ที่วาดเอง** (ตราสัญลักษณ์, การ์ดแคมเปญ, ลายขอบ, ผิวกระดาษ) ไม่มีลิขสิทธิ์ใคร
  → ถ้าผู้ใช้ตั้ง `GEMINI_API_KEY` ภายหลัง ค่อยเจนภาพ raster มาแทนได้ (ideas)
- Design brief: [`../design/visual-theme.md`](../design/visual-theme.md)

## ตัดสินใจ
- ธีมเดียว (ไม่แยก light/dark): พื้นไม้/หนังเข้ม + แผงกระดาษ parchment + หมึก + แดงเลือดหมู + ทอง
- ฟอนต์ Google Fonts: Cinzel (หัวข้อ) + Trirong (เนื้อความ ไทย+อังกฤษ); ออฟไลน์ก็ fallback เป็น serif
- ไม่เปลี่ยน flow / data-testid / protocol — เป็นงานหน้าตาล้วน
