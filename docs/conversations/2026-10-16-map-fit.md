# 2026-10-16 — แมพพอดีกรอบ + แบ่งจอ + จิ้มเดิน

## คำขอ (คำต่อคำ)
> งานแก้เพิ่ม map ตอนนี้ out of border คือมันต้องเลื่อนถูกมั้ย มันไม่ดีเลย เราต้อง ขอเป็น ภาพ ต้อง fit กับขอบเสมอ ซึ่งขอบจะสามารถขยาย หรือลดขนาดได้ แบ่งหน้าจอให้ชัดเจนไปเลย ฝั่งไหนข้อมูล ฝั่งไหนแมพ และวิธีการเดินของตัวละครผู้เล่น ใช้วิธีการจิ้มที่หน้าจอ จิ้มลงไปบนผนที่ เนื่องจากแบ่งเป็น grid แล้ว หลักการคือ รูปภาพเป็นพื้นหลังเฉยๆ เราเอากริดระบบเาไปทับเลย แล้วเดินบนกริดของเรา  dm สามารถขยาย หรือ ลดขนาด กริดได้ ตามขอบที่มี

## คำถาม → คำตอบ
| คำถาม | คำตอบ |
|---|---|
| ขยาย/ลดกรอบยังไง | **ลากเส้นแบ่ง**: แมพซ้าย ข้อมูลขวา มีแถบลากตรงกลาง แมพ fit กรอบเสมอ ไม่ต้องเลื่อน · มือถือ: แมพบน ข้อมูลล่าง |
| DM ตั้งกริดยังไง | **ช่องสี่เหลี่ยมจัตุรัส ตั้งจำนวนคอลัมน์** (+/−) แถวคำนวณจากสัดส่วนรูป กริดคลุมทั้งรูปเสมอ ไม่มีการเลื่อน offset |
| ผู้เล่นเดินยังไง | **จิ้มช่องปลายทาง** แล้ว token ตัวเองเดินไปเลย · DM จิ้ม token เพื่อเลือก แล้วจิ้มช่องปลายทาง |
