## สรุปปุ่ม reload (ผมออกแบบเอง)
- TUI: ปุ่ม **⟳ RELOAD** (คลิกได้) + คีย์ `r` → build ใหม่ (web + Go) → ถ้า build ผ่าน: ปิด server อย่างปลอดภัย → exec binary ใหม่ → เริ่ม server เอง (ข้ามหน้ายินดีต้อนรับ)
- build ไม่ผ่าน → server เดิมรันต่อ, error ขึ้นใน log
- ห้องอยู่ใน memory → reload = ห้องรีเซ็ต; ถ้ามีคนต่ออยู่ ต้องกด `r` ซ้ำเพื่อยืนยัน
- browser: เชื่อมต่อใหม่แล้วเจอ build id ใหม่ → refresh หน้าเองอัตโนมัติ (ได้โค้ดหน้าเว็บใหม่)
