# 2026-10-16 — ชื่อ NPC ห้ามซ้ำ + ปุ่ม duplicate monster

## คำขอผู้ใช้ (คำต่อคำ)

> ตอนตั้งชื่อ บังคับให้ตั้งชื่อซ้ำไม่ได้ ถ้ามี Goblin 8 ตัวก็ต้องใส่เลขด้วย และพิ่มปุ่ม duplicate monster ด้วย ถ้ากดแล้วจะเพิ่มอีกตัว เริ่มต้นที่เลขต่อจากนั้นเลย เช่น ถ้ามีมีเลข จะเป็น 2,3,4 ถ้ามีเลขอยู่แล้ว เช่น 5 ก้จะต่อเป็น 6 ถ้ามีอยู่แล้ว 5 ตัว แล้ว duplicate จาตัวที่ 2 ให้ทำการอ่านว่ามีชื่อซ้ำกี่ตัว แล้วเพิ่มลงไปตรงท้ายสุด ไหนมีอะไรอีกไหม

## คำถามและคำตอบ

| คำถาม | คำตอบ |
|---|---|
| ปุ่ม duplicate อยู่ไหน ตัวใหม่ได้อะไร | แถว token ในรายการ token: HP เต็มจาก pool, ซ่อน/ไม่ซ่อนตามตัวเดิม, ช่องว่างใกล้ตัวเดิม |
| ห้ามซ้ำแค่ไหน | ชื่อใน pool ห้ามซ้ำ + ชื่อ token ในฉากเดียวกันห้ามซ้ำ (คนละฉากซ้ำได้) ไม่สนตัวพิมพ์เล็ก/ใหญ่ |
| รูปแบบเลข | `Goblin #2` โชว์ทุกที่ (แมพ, บันทึกการเล่น, ป้าย) ให้ผู้เล่นด้วย |
