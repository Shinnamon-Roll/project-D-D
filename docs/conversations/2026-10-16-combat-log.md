# 2026-10-16 — โหมดต่อสู้ + ปุ่มโจมตี + Log ของ DM

## คำขอ (คำต่อคำ)
> ในฝั่งของ DM เพิ่ม Log เข้าไปด้วย เพิ่ม list menu เข้าไปว่าเป็น Log มีใครทำอะไรบ้าง แต่ก่อนหน้านั้น หากผู้เล่นกดโจมตี (เพิ่มปุ่มโจมตี หากเข้าสู่เฝสต่อสู้ DM จะเป้นคนกด โหมดต่อสู้) จะมีปุ่มโจมตีเพิ่มเข้ามา หากผู้เล่นกดดจมตี จะมีแจ้งเตือนมาหา Dm จากนั้นต้องทอยลุกเต๋า แล้ว Dm จะกด ว่า โดน หรือ ไม่โดน แล้วค่อยบันทึกลง LOG โยถ้า โดน จะมีคำว่าโดนกลางจอใหญ่ญ่ๆ ของฝั่ง player ถ้าไม่โดนก็ใหญ่พอๆกัน และลบการย้ายด้วยตัวเลข ที่แบบ กรอกเลขเพื่อย้ายตำแหน่ง เอาออกได้เลย

## คำถาม → คำตอบ
| คำถาม | คำตอบ |
|---|---|
| กดโจมตีต้องเลือกเป้าไหม | **เลือกเป้า** — จิ้ม token ศัตรูบนแมพ (หรือเลือกจากรายการ) แล้วส่ง |
| ใครเห็นคำว่า โดน/ไม่โดน กลางจอ | **ผู้เล่นทุกคน** ~2 วินาที |
| โดนแล้วจัดการดาเมจยังไง | **DM ใส่ดาเมจ หักอัตโนมัติ** (ช่องไม่บังคับ; เว้นว่าง = บันทึกแค่ว่าโดน) |
