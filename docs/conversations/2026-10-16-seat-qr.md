# 2026-10-16 — QR code เข้านั่งที่นั่ง

## คำขอ (คำต่อคำ)
> เพิ่มระบบ สแกน qrcode เพื่อให้สามารถ เข้าไปนั่งที่นั่งนั้นได้ เป้นปุ่ม สแกน qrcode กดแล้วจะโชว์ qrcode กลางจอ แล้ว label ลำดับที่นั่งไว้ด้วย สแกนแล้วจะเข้านั่งที่นั่งนั้นๆเลบ

## คำถาม → คำตอบ
| คำถาม | คำตอบ |
|---|---|
| server ฟังแค่ 127.0.0.1 มือถือเข้าไม่ได้ จะทำยังไง | **เปิดให้ Wi-Fi เข้าได้**: `make run` ฟัง `0.0.0.0` เป็นค่าเริ่มต้น, QR ใช้ IP วง LAN ของเครื่อง (ยอมรับว่าใครอยู่ Wi-Fi เดียวกันเข้าได้โดยไม่มีรหัส) |
| สแกนแล้วนั่งเลย หรือใส่ชื่อก่อน | **ใส่ชื่อก่อน**: เปิดหน้าที่เลือกที่นั่งไว้แล้ว + ช่องชื่อ → กด "นั่ง" ครั้งเดียว |
| ใครเห็นปุ่ม | **DM + DM ร่วม** |
