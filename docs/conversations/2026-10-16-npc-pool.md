# 2026-10-16 — NPC Pool ของ DM

## คำขอ (คำต่อคำ)
> เพิ่ม NPC Pool ให้ DM เป็น white label เหมือนกัน หลักการคือ ปุ่ม + เพื่อให้ dm เพิ่มตัวละคร แล้วจะมีให้ใส่รุป ใส่ชื่อ ปกิปิด หรือไม่ปกปิด เลือด เท่านี้แหละ

## คำถาม → คำตอบ
| คำถาม | คำตอบ |
|---|---|
| "ปกปิด" หมายถึง | **ซ่อนทั้ง token** — ผู้เล่นไม่เห็นเลย (server ไม่ส่งให้), DM เห็นแบบโปร่ง, สลับเปิดเผยได้ตลอด |
| เก็บ pool ถาวรไหม | **เก็บลงไฟล์** `data/npcs.json` (ข้างโน้ต) |

## สรุป
- Spec: [`../features/npc-pool.md`](../features/npc-pool.md)
- ผมเลือกเอง: HP ของ NPC เห็นแค่ DM (ผู้เล่นไม่ได้รับค่า HP) — ตรงกับไอเดียเดิม "HP มอนสเตอร์ที่ DM เห็นคนเดียว"

## คำขอเพิ่ม (คำต่อคำ)
> สำหรบ NPC ถ้าคลิกที่รูปตา จะเป้นการเปิดปิด hidding โหมด เหมือนเป็น toggle คิลกทีนึงตาเปิด อีกทีตาปิด only dashboard not eye icon on map

## สรุป
- ไอคอนตาในฝั่งข้อมูล (dashboard) = ปุ่ม toggle: ตาเปิด = ผู้เล่นเห็น, ตาปิด = ซ่อน; คลิกสลับ
  - รายการ token: สลับ `token.setHidden` · รายการ NPC Pool: สลับค่าเริ่มต้น `hidden` ตอนวาง (`npc.update`)
- **เอาไอคอนตาบนแมพออก** (token ที่ซ่อนยังโปร่งสำหรับ DM เหมือนเดิม)
