# Fighter (นักรบ)

Fighter คือนักสู้มืออาชีพที่ใช้อาวุธและเกราะได้ทุกแบบ ไม่มีเวท แต่ทนทานและโจมตีได้หลายครั้งต่อเทิร์น  
Weapon Mastery ให้อาวุธแต่ละชนิดมีลูกเล่นของตัวเอง เล่นง่ายแต่ยังมีทางเลือกเชิงกลยุทธ์

Research ประกอบ: [`../../research/classes/phb-2024/fighter.md`](../../research/classes/phb-2024/fighter.md) · กลไกและชื่อ feature อ้างอิง SRD 5.2.1 (CC BY 4.0) คำอธิบายเขียนเองด้วยคำของเรา

## ข้อมูลหลัก
| | |
|---|---|
| Hit Die | d10 |
| Primary ability | STR, DEX |
| Saving throws | STR, CON |
| Armor | เกราะเบา, กลาง, หนัก, โล่ |
| Weapons | อาวุธ Simple และ Martial |
| Tools | — |
| Skills | เลือก 2 จาก acrobatics, animal-handling, athletics, history, insight, intimidation, persuasion, perception, survival |
| Spellcasting | ไม่มี |

## Feature ตามเลเวล
| Level | Feature | สรุป |
|---|---|---|
| 1 | Fighting Style | ได้ Fighting Style feat 1 อัน (แนะนำ Defense) เปลี่ยนเป็นอันอื่นได้ทุกครั้งที่ขึ้นเลเวล Fighter — เพิ่มเองเป็น custom ability |
| 1 | Second Wind | Bonus Action ฟื้น HP 1d10 + เลเวล Fighter จำนวนครั้งดูตาราง Short Rest คืน 1 ครั้ง Long Rest คืนหมด |
| 1 | Weapon Mastery | ใช้ mastery property ของอาวุธ Simple/Martial ที่เลือกได้ (จำนวนชนิดดูตาราง) หลัง Long Rest เปลี่ยนได้ 1 ชนิด |
| 2 | Action Surge | ในเทิร์นของตัวเอง ได้ action เพิ่ม 1 ครั้ง (ยกเว้น Magic action) ใช้แล้วต้องรอ Short หรือ Long Rest |
| 2 | Tactical Mind | เช็ก ability พลาด ใช้ Second Wind 1 ครั้งทอย 1d10 บวกเข้าเช็กแทนการฟื้น HP ถ้ายังพลาดอยู่ไม่เสีย use |

| 9 | Tactical Master | ตอนโจมตีด้วยอาวุธที่ใช้ mastery ได้ เปลี่ยน property ของการโจมตีนั้นเป็น Push, Sap หรือ Slow ได้ |

| 13 | Indomitable (two uses) | Indomitable ใช้ได้ 2 ครั้งต่อ Long Rest |
| 13 | Studied Attacks | โจมตีพลาดเป้าไหน การโจมตีครั้งถัดไปใส่เป้านั้นก่อนจบเทิร์นหน้าได้ Advantage |
