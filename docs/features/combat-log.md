# Feature: โหมดต่อสู้ + โจมตี + Log ของ DM (v0.14.0)

ที่มา: [`../conversations/2026-10-16-combat-log.md`](../conversations/2026-10-16-combat-log.md)

## โหมดต่อสู้
- DM/co-DM กดสวิตช์ **"โหมดต่อสู้"** (แถบปาร์ตี้ / เมนู DM) → `combat.set {on}` (สถานะ `playing`); state `combat: boolean`; feed: "เข้าสู่โหมดต่อสู้" / "จบการต่อสู้"
- ปิดโหมดต่อสู้ → การโจมตีที่ค้างถูกยกเลิกทั้งหมด

## โจมตี (ผู้เล่น)
- เมื่อ `combat = true` ชีทผู้เล่นมีปุ่ม **"โจมตี"** (`attack-btn`)
- กด → โหมดเลือกเป้า: จิ้ม token บนแมพ (token ที่มองเห็น ในฉากปัจจุบัน ไม่ใช่ตัวเอง) **หรือ** เลือกจากรายการ (`attack-target-select`) → ยืนยัน (`attack-confirm`) → `attack.declare {targetTokenId}`; Esc/ยกเลิก ออกจากโหมดเลือก
- ระหว่างรอ: แถบ "รอ DM ตัดสิน — ทอยลูกเต๋าของคุณ!" + ปุ่มยกเลิก (`attack.cancel {}`)
- ผู้เล่น 1 คน ค้างได้ 1 การโจมตี
- Server: target ต้องมีอยู่, อยู่ฉากเดียวกับผู้โจมตี, **ไม่ซ่อน** (error เดียวกับ token ไม่มีอยู่ — กันรั่ว), ผู้โจมตีมีตัวละครและ token ในฉาก

## ตัดสิน (DM)
- การโจมตีค้างแสดงเป็น **การแจ้งเตือน** มุมบนของ DM (`attack-alert-<id>`, aria-live assertive) + เสียง/สั่นไม่ต้อง: "อายลา โจมตี Goblin #2"
- ปุ่ม **โดน** (`attack-hit-<id>`) / **ไม่โดน** (`attack-miss-<id>`) + ช่องดาเมจไม่บังคับ (`attack-dmg-<id>`, 0–999) → `attack.resolve {attackId, hit, damage?}`
  - โดน + ดาเมจ → หัก HP ของเป้า (NPC token `hp` หรือ character `hp`), clamp 0
- state ส่งการโจมตีค้าง `attacks: [{id, byCharacterId, byName: L, targetTokenId, targetName, at}]` **ให้ DM เท่านั้น**; ผู้เล่นได้แค่ `myAttack?: {id, targetName}` ของตัวเอง
- ผลไปที่ **feed** สาธารณะ: "อายลา → Goblin #2: โดน!" (เป้าเป็น NPC: ไม่บอกตัวเลขดาเมจ/HP; เป้าเป็นตัวละคร: บอก −ดาเมจ และ HP ใหม่) · ชื่อ NPC ใน feed และป้ายเป็นชื่อ token เต็ม รวม `#n` เสมอ ([`npc-names.md`](npc-names.md))

## ป้ายใหญ่กลางจอ (ทุกคน)
- หลัง resolve server ส่งข้อความชั่วคราว `{type: "banner", payload: {kind: "hit"|"miss", text: L}}` ให้ทุก connection (ไม่อยู่ใน state)
- หน้าจอทุกคนแสดง **"โดน!"** / **"ไม่โดน!"** ตัวใหญ่กลางจอ (+ บรรทัดเล็ก "อายลา → Goblin #2") ~2 วินาทีแล้วจางหาย; โดน = แดงเลือดหมู/ทอง, ไม่โดน = เหล็ก/เทา ขนาดพอๆ กัน; motion scale-in; reduced-motion = แค่ fade; `pointer-events: none`; `aria-live` สำหรับ screen reader

## Log ของ DM
- เมนู DM หัวข้อใหม่ **"Log"** — รายการ "ใครทำอะไร" ใหม่สุดบน: เวลา, ผู้กระทำ, การกระทำ
- บันทึกทุก event ที่สำเร็จ: เข้า/ออกห้อง, นั่ง/ลุก/พร้อม, เลือกตัวละคร, ย้าย token (จาก→ถึง), โจมตี/ตัดสิน (รวมดาเมจ), HP, เลเวล, ability/AC, ใช้ spell slot/counter/hit dice, คาถา/ความสามารถของฉัน, ให้/ลบของ, พักสั้น/พักยาว, ฉาก/กริด/หมอก, NPC (เพิ่ม/วาง/ซ่อน/เปิดเผย/HP), โน้ต (แค่ "แก้โน้ต <หัวข้อ>"), roster, โหมดต่อสู้
- **ไม่ใช่แค่การต่อสู้ — ทุกอย่าง** (คำขอเพิ่ม: "not only battle log it's all log when we move when we died when we fight")
- **ตาย/ล้ม**: เมื่อ HP ลดถึง 0 ไม่ว่าจากทางไหน (ดาเมจโจมตี, DM −HP, token.adjustHp) → บรรทัดพิเศษ "💀 <ชื่อ> ล้มลง (HP 0)" ใน Log + feed สาธารณะ (ตัวละคร: "หมดสติ"; NPC ที่มองเห็น: "ล้มลง"; NPC ที่ซ่อน: Log ของ DM เท่านั้น); ฟื้น (HP จาก 0 → >0) → "<ชื่อ> ฟื้นขึ้น"
- DM/co-DM เท่านั้น; ไม่มี clientId; เก็บใน memory ล่าสุด 300 รายการ
- ส่งแบบ **ต่อท้าย**: ตอน hello / กลายเป็น DM ส่งทั้งหมด (`dmLog` ใน state), หลังจากนั้นส่งข้อความ `{type: "log", payload: entry}` เฉพาะ DM (ไม่ใส่ทั้งก้อนใน state ทุกครั้ง)
- entry: `{at, actor: string, text: L}`

## ลบการย้ายด้วยตัวเลข
- รายการ token: เอาช่องตัวเลข col/row + ปุ่ม "ย้าย" ออก (ย้ายด้วยการจิ้มบนแมพเท่านั้น); ยังเหลือชื่อ, ตำแหน่ง, ตา toggle, HP, ลบ
- e2e เปลี่ยนไปจิ้มบน canvas
