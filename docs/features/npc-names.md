# Feature: ชื่อ NPC ไม่ซ้ำ + ปุ่ม duplicate monster

บทสนทนา: [`../conversations/2026-10-16-npc-names.md`](../conversations/2026-10-16-npc-names.md) · ต่อยอดจาก [`npc-pool.md`](npc-pool.md), [`npc-actions.md`](npc-actions.md)

## ชื่อใน NPC Pool
- `npc.add` / `npc.update`: ชื่อซ้ำกับ NPC อื่นใน pool = error `that name is already in the pool` (เทียบแบบ trim + ไม่สนตัวพิมพ์เล็ก/ใหญ่; update ชื่อเดิมของตัวเองได้)
- pool เก่าใน `data/npcs.json` ที่มีชื่อซ้ำอยู่แล้ว: โหลดได้ตามเดิม (ไม่ลบ ไม่เปลี่ยนชื่อ) แค่แก้/เพิ่มใหม่ต้องไม่ซ้ำ

## ชื่อ token ในฉาก
- ชื่อ token ในฉากเดียวกันไม่ซ้ำกันเสมอ (คนละฉากซ้ำได้) เทียบแบบไม่สนตัวพิมพ์
- รูปแบบ: `<ชื่อฐาน>` สำหรับตัวแรก แล้ว `<ชื่อฐาน> #2`, `#3`, … · ชื่อฐาน = ชื่อที่ตัด ` #<เลข>` ท้ายสุดออก
- **เลขถัดไป = เลขสูงสุดของชื่อฐานเดียวกัน + 1** (ตัวไม่มีเลขนับเป็น 1) — ไม่ใช่นับจำนวน
  - มี `Goblin` → ตัวใหม่ `Goblin #2`, แล้ว `#3`, `#4`
  - มี `Goblin #5` เป็นเลขสูงสุด → `Goblin #6`
  - มี 5 ตัว (`Goblin`, `#2`…`#5`) แล้ว duplicate จาก `#2` → `Goblin #6` (ต่อท้ายสุด)
  - ชื่อฐานที่ลงท้าย `#เลข` อยู่แล้วใน pool (เช่น pool ชื่อ `Goblin #5`) → ฐาน `Goblin` เริ่มที่ 5 แล้วต่อ 6
- ใช้กติกาเดียวกันทุกทางที่สร้าง token NPC: `npc.place` (วางจาก pool) และ `token.duplicate`
- ชื่อ token ตัวละครผู้เล่นไม่ถูกเปลี่ยน แต่นับเป็นชื่อที่ถูกใช้แล้ว (NPC จะข้ามไปเลขถัดไป)

## ความลับ: ตัวที่ซ่อนห้ามรั่วผ่านเลข
ผู้เล่นต้องอนุมานไม่ได้ว่ามีตัวซ่อน (เช่น เห็น `#3` แต่ไม่มี `#2`)
- token ที่ **มองเห็น** (วางแบบไม่ซ่อน, duplicate ตัวที่มองเห็น, หรือเพิ่งถูกเปิดเผย): ได้ชื่อถัดไป **นับจาก token ที่มองเห็นเท่านั้น** (ไม่มีตัวที่มองเห็นในฐานนั้น = ชื่อฐานเปล่า)
  - เปิดเผย (`token.setHidden false`): ถ้าชื่อเดิมไม่ใช่ชื่อถัดไปของฝั่งที่มองเห็น ให้เปลี่ยนเป็นชื่อนั้น
- ถ้าชื่อที่ได้ไปชนกับ token **ที่ซ่อนอยู่** → เปลี่ยนชื่อตัวที่ซ่อนแทน เป็นเลขสูงสุดของทั้งฉาก + 1 (ข้อมูล DM เท่านั้น)
- token ที่ **ซ่อน** ตอนสร้าง: ได้เลขสูงสุดของทั้งฉาก (รวมที่ซ่อน) + 1
- ทุกครั้งที่เปลี่ยนชื่อ token อัตโนมัติ DM log มีบรรทัดบอก (เฉพาะ DM)

## ปุ่ม duplicate (DM)
- แถว token NPC ในรายการ token: ปุ่ม **Duplicate** (`token-dup-<tokenId>`) — ทุกสถานะ `playing` ไม่ต้องเปิดโหมดต่อสู้
- `token.duplicate {tokenId}` — DM/co-DM, `playing`, token ต้องเป็น NPC (ไม่ใช่ตัวละคร)
  - ตัวใหม่: รูป + `hpMax` เดียวกัน, `hp = hpMax`, `hidden` เท่าตัวเดิม, `npcId` เดิม, ชื่อตามกติกาด้านบน
  - ตำแหน่ง: ช่องว่างที่ใกล้ตัวเดิมที่สุด (กติกา MaxPerCell เดิม, ตัวที่มองเห็นไม่นับตัวซ่อน) · ไม่มีที่ = error เดิมของการวาง
  - บันทึกการเล่น + DM log: "เพิ่ม Goblin #6" (ตัวซ่อน = DM log เท่านั้น)

## เลข #n โชว์ทุกที่
- บันทึกการเล่นและป้าย (รวม `npc.act` และ `attack.resolve`) ใช้ชื่อ token เต็ม รวม `#n` — ยกเลิกการตัดเลขของ `npcPublicName`
- อัปเดต `npc-actions.md` และ `combat-log.md` ให้ตรง

## นอก scope
- DM เปลี่ยนชื่อ token เอง
- เรียงเลขใหม่ให้ชิดกันเมื่อมีตัวถูกลบ
