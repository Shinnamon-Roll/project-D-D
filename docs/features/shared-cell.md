# Feature: หลายตัวในช่องเดียว (v0.13.0)

ที่มา: [`../conversations/2026-10-16-shared-cell.md`](../conversations/2026-10-16-shared-cell.md)

## กติกา
- ช่องหนึ่งมี token ที่ **มองเห็นได้** สูงสุด **4** ตัว (`MaxPerCell = 4`)
- นับเฉพาะ token ที่ไม่ซ่อน (`hidden: false`) — NPC ที่ซ่อนไม่กินโควตา (ผู้เล่นจะไม่รู้ว่ามีตัวซ่อน)
- Server (`internal/room`):
  - `token.move` เข้าช่องที่มีตัวมองเห็นครบ 4 แล้ว (ไม่นับตัวที่กำลังย้ายเอง) → error `that cell is full (max 4)`
  - ย้ายตัวที่ **ซ่อน** ไม่ติดโควตา (DM ซ่อนวางที่ไหนก็ได้)
  - `token.setHidden` → เปิดเผยในช่องที่ครบ 4 แล้ว → error `that cell is full (max 4)` (DM ต้องย้ายก่อน)
  - `npc.place` (visible) / `scene.select` วาง token อัตโนมัติ → ข้ามช่องที่ครบ 4
  - `scene.update` กริดหด → clamp แล้วถ้าช่องปลายทางเกิน 4 ให้หาช่องว่างใกล้สุด
- ไม่ต้องเปลี่ยน protocol shape

## การวาด (MapStage)
| ตัวในช่อง | ตำแหน่ง | รัศมี |
|---|---|---|
| 1 | กลางช่อง | 0.42 ช่อง (เดิม) |
| 2 | ซ้าย / ขวา | 0.24 ช่อง |
| 3–4 | มุม ซ้ายบน, ขวาบน, ซ้ายล่าง, ขวาล่าง (3 ตัว = 3 มุมแรก) | 0.22 ช่อง |
- เรียงตำแหน่งตาม token id (คงที่ ไม่สลับไปมา)
- DM: token ที่ซ่อนในช่องเดียวกันวาดซ้อนตำแหน่งตามลำดับต่อจากตัวมองเห็น (ถ้าเกิน 4 ช่อง → ซ้อนมุมล่างขวา) แบบโปร่งเหมือนเดิม
- ช่องที่มีหลายตัว: ซ่อนชื่อใต้ token (แสดงเมื่อเลือก) — รายการ token ในฝั่งข้อมูลยังบอกชื่อครบ
- จิ้ม: ผู้เล่นจิ้มช่อง → token ตัวเองย้ายไป (จิ้มช่องที่ตัวเองอยู่ = ไม่ทำอะไร); DM จิ้มวงกลมเล็กตัวไหน = เลือกตัวนั้น
- เปลี่ยนตำแหน่ง/ขนาดแบบลื่น (tween ~150ms) เมื่อมีตัวเข้า/ออกช่อง; `prefers-reduced-motion` = ทันที
