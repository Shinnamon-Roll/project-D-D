# Druid (ดรูอิด)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
Druid เป็นผู้ใช้เวทสายธรรมชาติแบบ full caster ที่ใช้ Wisdom เด่นทั้งด้านรักษา ควบคุมพื้นที่ และเรียกพลังธาตุ
จุดขายคือ Wild Shape แปลงร่างเป็นสัตว์เพื่อสอดแนม เดินทาง หรือเข้าสู้ ผู้เล่นต้องสลับระหว่างร่างคนที่ร่ายเวทกับร่างสัตว์ให้ถูกจังหวะ

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: ผู้พิทักษ์ป่า, นักบวชสายบรรพกาล, คนเลี้ยงสัตว์ที่สื่อสารกับสัตว์ได้, คนนอกที่ไม่ไว้ใจเมือง
- แรงจูงใจ: รักษาสมดุลธรรมชาติ, ปกป้องดินแดนหรือสัตว์ที่ผูกพัน, ต่อต้านสิ่งผิดธรรมชาติ (undead, เวทที่ทำลายป่า)
- จุดอ่อน/ข้อขัดแย้ง: มองปัญหาของคนว่าเล็กกว่าปัญหาของป่า, ดื้อต่อกฎของอารยธรรม, ลังเลระหว่างความเมตตากับ "ธรรมชาติต้องคัดสรร"
- ไอเดียตัวละคร:
  - หญิงชราเก็บสมุนไพรที่คนในหมู่บ้านกลัวแต่แอบมาขอยารักษาทุกคืน
  - เด็กหนุ่มที่ถูกหมาป่าเลี้ยง กำลังหัดพูดภาษาคน
  - ทหารปลดประจำการที่หันมาปลูกป่าบนสนามรบเก่า
  - ชาวเรือที่เชื่อว่าคลื่นพายุคือเสียงของเทพทะเลที่ต้องฟัง

## บทบาทในปาร์ตี้
support / control / utility / scout (รองลงมา: damage จากธาตุ, tank ชั่วคราวด้วย Wild Shape) · ความยาก: กลาง-ยาก
(รายการเวทยาวและต้องจัดการ Wild Shape + spell slot พร้อมกัน)

## แนวคิดสำหรับแอปเรา
- mana สูง, HP กลาง, str/end ต่ำ, agi กลาง: ตัว support/control ที่ใช้ mana ทั้งรักษาและควบคุมพื้นที่
- skill "แปลงร่าง" ใช้ mana ก้อนใหญ่ แลกกับ HP ชั่วคราว + เปลี่ยน str/agi ชั่วคราวตามร่าง (เช่น หมี = str สูง, แมว = agi สูง)
- custom skill ตัวอย่าง: รากไม้รัดศัตรู (หยุดการเดิน 1 เทิร์น), สมุนไพรรักษา, คุยกับสัตว์เพื่อสอดแนม
