# Ranger (พรานป่า)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
นักล่าแห่งพื้นที่ป่าเถื่อน ผสมฝีมืออาวุธ (ส่วนใหญ่ธนู) กับเวทธรรมชาติแบบ half caster
หัวใจของคลาสคือ Hunter's Mark: ปักเป้าหมายแล้วตามเก็บด้วยดาเมจเพิ่ม พร้อมทักษะสำรวจ เดินทาง และสอดแนม

## นิสัยและบุคลิก (roleplay)
- archetype: พรานเงียบขรึม, ผู้นำทางชายแดน, ผู้พิทักษ์ป่า, นักล่าค่าหัวสัตว์ร้าย
- แรงจูงใจ: ปกป้องดินแดน/ชุมชนชายขอบ, ตามล่าศัตรูที่เคยทำลายบ้าน, อยู่กับธรรมชาติมากกว่าเมือง
- จุดอ่อน/ข้อขัดแย้งภายใน: ไม่ไว้ใจคนเมือง เข้าสังคมไม่เก่ง, ยึดติดกับการไล่ล่าจนลืมเป้าหมายใหญ่
- ไอเดียตัวละคร:
  - คนนำทางกองคาราวานที่รู้ทุกทางลัดบนภูเขา
  - ผู้รอดชีวิตจากหมู่บ้านที่ถูกฝูงหมาป่าปีศาจทำลาย
  - นักล่าค่าหัวที่เก็บเขี้ยวสัตว์ทุกตัวที่ล่าได้เป็นสร้อย
  - ผู้เฝ้าป่าที่ถูกชาวบ้านมองว่าเป็นคนนอก

## บทบาทในปาร์ตี้
damage (ranged / single target) / scout / utility (สำรวจ, track, support spell บางส่วน) · ความยาก: กลาง (ต้องจัดการ Concentration ของ Hunter's Mark กับ spell อื่น)

## แนวคิดสำหรับแอปเรา
- agi เป็นหลัก, HP กลาง-สูง, mana ปานกลาง: skill หลักคือ "mark เป้าหมาย" ที่กิน mana ครั้งเดียวแล้วโจมตีเป้านั้นแรงขึ้นจนกว่าจะเปลี่ยนเป้า
- เหมาะกับโจมตีระยะไกลบน grid + bonus การเดิน (Roving) เช่นเดินได้ไกลกว่าคลาสอื่น 1-2 ช่อง
- ทักษะนอกการต่อสู้ (track, นำทาง) ให้ DM ใช้เป็น roleplay ไม่ต้องทำเป็นระบบในแอป
