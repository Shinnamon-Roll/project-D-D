# Monk (นักพรตยุทธ์)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
Monk คือนักสู้มือเปล่าที่ไม่ใส่เกราะ เร็ว คล่องตัว และตีหลายครั้งต่อเทิร์นด้วย Martial Arts
ใช้ Focus Points เปิดท่าพิเศษ เช่น ตีรัว หลบ วิ่งไว และทำให้ศัตรู Stunned เล่นแบบวิ่งเข้าออกแนวหน้าอยู่ตลอด

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: ศิษย์วัดบนภูเขา, นักบวชผู้ฝึกตน, นักต่อสู้ข้างถนน, ผู้ไถ่บาปที่ละทิ้งอาวุธ
- แรงจูงใจ: ฝึกตนสู่ความสมบูรณ์แบบ, ปกป้องวัดหรือคำสอน, ตามหาอาจารย์ที่หายไป, ชดใช้อดีต
- จุดอ่อน/ข้อขัดแย้ง: วินัยเคร่งจนเข้ากับคนยาก, ใจร้อนแต่ต้องสงบ, ยึดติดกับคำสอนจนตัดสินใจไม่ได้เมื่อคำสอนขัดกับความถูกต้อง
- ไอเดียตัวละคร:
  - ศิษย์คนสุดท้ายของวัดที่ถูกเผา เดินทางตามหาคัมภีร์ที่ถูกขโมย
  - อดีตนักชกใต้ดินที่ฝึกสมาธิเพื่อคุมโทสะ
  - พระธุดงค์ที่ปฏิญาณไม่ถือของเกินจำเป็น แต่ชอบชาดีมาก
  - ลูกครึ่งเอลฟ์ที่ใช้เวลาครึ่งชีวิตฝึกท่าเดียวจนสมบูรณ์

## บทบาทในปาร์ตี้
damage / scout / control (Stunning Strike) · ความยาก: กลาง (ต้องบริหาร Focus Points และตำแหน่ง เพราะ AC ไม่สูงมาก)

## แนวคิดสำหรับแอปเรา
- agi สูงมาก, str กลาง, end ต่ำ-กลาง, HP กลาง, mana กลาง (mana = Focus Points ฟื้นเร็ว)
- skill ใช้ mana น้อยแต่ใช้บ่อย: "ตีรัว" (โจมตีเพิ่ม), "ก้าวลม" (เดินเพิ่มช่อง), "จุดสลบ" (ศัตรูข้ามเทิร์น)
- เดินได้ไกลกว่าคลาสอื่นบนกริด (agi สูง) เหมาะเป็นตัวไล่ล่า/ตัดหลังศัตรู
