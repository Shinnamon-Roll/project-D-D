# Cleric (นักบวช)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
ผู้รับพลังจากเทพหรืออุดมการณ์ศักดิ์สิทธิ์ เป็น full caster ด้วย Wisdom ที่ฮีล บัฟ และตีได้ในตัว
ใส่ Medium armor + โล่ได้ จึงยืนแถวหน้าได้บ้าง และใช้ Channel Divinity ฮีล/ทำดาเมจหรือไล่ Undead

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: นักบวชประจำวัด, อัศวินศักดิ์สิทธิ์, หมอรักษาคนยาก, ผู้ถูกเทพเลือกโดยไม่ได้ตั้งใจ
- แรงจูงใจ: เผยแผ่ศรัทธา, ปกป้องผู้อ่อนแอ, ทำตามนิมิต/คำสั่งของเทพ, ทำลายความชั่ว (เช่น Undead)
- จุดอ่อน/ข้อขัดแย้งภายใน: ศรัทธาสั่นคลอนเมื่อเทพเงียบ, หัวแข็งเรื่องศีลธรรม, ขัดแย้งระหว่างคำสั่งวัดกับสิ่งที่ถูกต้อง
- ไอเดียตัวละคร:
  - หมอประจำหมู่บ้านที่เพิ่งรู้ว่าพลังรักษามาจากเทพที่ตัวเองไม่เคยนับถือ
  - อดีตทหารที่หันมาบวช หลังรอดตายจากสนามรบอย่างไม่มีเหตุผล
  - ผู้ดูแลสุสานที่ตั้งใจจะส่งวิญญาณเร่ร่อนทุกดวงไปสู่สุข
  - นักบวชหนุ่มที่ถูกส่งออกมาตามหาคัมภีร์ที่ถูกขโมยไป

## บทบาทในปาร์ตี้
support (healer) + damage/tank รอง (ขึ้นกับ Divine Order) · ความยาก: **กลาง**

## ข้อมูลหลัก
| | |
|---|---|
| Hit Die | d8 |
| HP เลเวล 1 / ต่อเลเวล | 8 + CON mod / 1d8 (หรือ 5) + CON mod |
| Primary ability | Wisdom |
| Saving throws | Wisdom, Charisma |
| Armor / Weapons | Light, Medium armor, Shields / Simple weapons (Protector ได้ Heavy armor + Martial weapons เพิ่ม) |
| Tools / Skills | ไม่มี tool / เลือก 2 จาก History, Insight, Medicine, Persuasion, Religion |
| Starting equipment | (A) Chain Shirt, Shield, Mace, Holy Symbol, Priest's Pack, 7 GP หรือ (B) 110 GP |
| Spellcasting | full caster · Wisdom · focus = Holy Symbol |
| Resource หลัก | spell slots + Channel Divinity (2 → 4 ครั้ง, Short Rest คืน 1, Long Rest คืนหมด) |

Life Domain · Light Domain · Trickery Domain · War Domain

## แนวคิดสำหรับแอปเรา
- stat: mana สูง, HP/end กลาง, str กลาง, agi ต่ำ (สายใส่เกราะ)
- skill ที่ใช้ mana = "ฮีล" (ฟื้น HP เพื่อน), "แสงศักดิ์สิทธิ์" (ดาเมจโดนแน่นอน แรงขึ้นกับ Undead), "พร" (บัฟเพื่อนทอยแม่นขึ้น)
- ให้ผู้เล่นเลือกแนว Protector (ยืนหน้า) หรือ Thaumaturge (เน้นเวท) เป็น custom skill ได้
