# Warlock (ผู้ทำสัญญา)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
Warlock ได้พลังเวทจากการทำสัญญากับสิ่งเหนือธรรมชาติ (patron) ใช้ Charisma ร่ายเวท
ใช้ Pact Magic: slot น้อยแต่เป็นเลเวลสูงสุดเสมอและคืนตอน Short Rest ปรับแต่งตัวละครด้วย Eldritch Invocations

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: คนสิ้นหวังที่ยอมแลกทุกอย่าง, นักแสวงหาความรู้ต้องห้าม, คนที่ถูกเลือกโดยไม่ได้ขอ, ผู้ศรัทธาที่บูชา patron
- แรงจูงใจ: อำนาจ, การแก้แค้น, ช่วยคนที่รัก, ความรู้ลับ, ใช้หนี้สัญญาให้หมด
- ความสัมพันธ์กับ patron (ข้อขัดแย้งหลัก): บางคนเคารพหรือรัก patron, บางคนรับใช้อย่างจำใจ, บางคนแอบวางแผนทรยศ;
  patron อาจเป็นเทวดา, fey, ปีศาจ, แม่มด หรือสิ่งจากนอกจักรวาล และอาจไม่บอกตัวตนตั้งแต่แรก;
  ถ้า patron มีเป้าหมายชั่ว เรื่องของตัวละครคือ "จะยอมทำตามไปได้แค่ไหน"
- ไอเดียตัวละคร:
  - หมอยาที่ทำสัญญากับปีศาจเพื่อรักษาลูกสาว และตอนนี้ปีศาจเริ่มทวงค่าตอบแทน
  - นักบวชตกยุคที่ได้ยินเสียงกระซิบจากดาวดวงหนึ่ง และเชื่อว่ามันคือพระเจ้า
  - เด็กที่หลงเข้าป่า fey แล้วกลับออกมาพร้อมสัญญาที่จำไม่ได้ว่าเซ็นตอนไหน
  - ทหารที่ได้รับพลังจาก celestial เพื่อล่าสิ่งชั่วร้าย แต่เริ่มสงสัยคำสั่ง

## บทบาทในปาร์ตี้
damage (ยิงเวทระยะไกลต่อเนื่อง) / face (Charisma) / utility (จาก Invocations) · ความยาก: กลาง (slot น้อย ต้องวางแผนพัก + เลือก Invocations)

## แนวคิดสำหรับแอปเรา
- HP กลาง, mana ก้อนเล็กแต่ฟื้นเร็ว (คืนเต็มเมื่อพักสั้น) ต่างจาก caster อื่นที่ mana ใหญ่แต่ฟื้นช้า
- skill หลักเป็นเวทยิงระยะไกลราคาถูก/ฟรี + เวทแรงไม่กี่บทที่ใช้ mana มาก; ท่าไม้ตายระดับสูง (Mystic Arcanum) ใช้ได้ 1 ครั้ง/เซสชัน
- custom skill 3 ช่อง เข้ากับ Invocations (ความสามารถเฉพาะตัวจาก patron); patron เป็นจุดเชื่อม story กับ DM
