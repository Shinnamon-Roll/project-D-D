# Rogue (นักย่องเบา)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
ผู้เชี่ยวชาญด้านทักษะและการลอบโจมตี ไม่มีเวท (ใน base class) แต่มี skill และ Expertise มากที่สุด
ในการต่อสู้หาจังหวะ Sneak Attack (ได้ 1 ครั้งต่อเทิร์น) ให้ดาเมจก้อนใหญ่ แล้วใช้ Cunning Action ซ่อน/ถอยออกจากอันตราย

## นิสัยและบุคลิก (roleplay)
- archetype: หัวขโมยเจ้าเล่ห์, สายลับ, นักต้มตุ๋น, มือสังหาร, นักผจญภัยสายสำรวจกับดัก
- แรงจูงใจ: เงิน, อิสระ, หนี้ที่ต้องใช้, ความภักดีต่อกลุ่ม/แก๊ง, ความตื่นเต้นจากความเสี่ยง
- จุดอ่อน/ข้อขัดแย้งภายใน: ไม่ไว้ใจใคร, โลภ, อดีตตามมาหลอกหลอน, ถูกเพื่อนในปาร์ตี้สงสัย
- ไอเดียตัวละคร:
  - เด็กข้างถนนที่โตมาในแก๊งขโมย แล้วหนีออกมาเพราะไม่อยากทำร้ายคน
  - นักเปิดหีบกุญแจรับจ้างที่ติดหนี้คนผิด
  - สายลับของเมืองที่แฝงตัวเข้าปาร์ตี้โดยยังไม่บอกใคร
  - นักต้มตุ๋นเสน่ห์แรงที่พูดเก่งกว่าใช้มีด

## บทบาทในปาร์ตี้
damage (burst single target) / scout / utility (กับดัก กุญแจ ทักษะ) / face (ถ้าเน้น Charisma skill) · ความยาก: ง่าย-กลาง (base ง่าย, Cunning Strike ช่วงหลังต้องคิดเลือก)

## Subclass ใน PHB 2024 (ชื่อเท่านั้น)
Arcane Trickster · Assassin · Soulknife · Thief

## แนวคิดสำหรับแอปเรา
- agi สูงสุด, HP ต่ำ-กลาง, mana น้อยหรือไม่ใช้: skill หลักเป็น passive "ลอบโจมตี" ดาเมจเพิ่มเมื่อมีเพื่อนยืนช่องติดเป้า (เช็คบน grid ได้ง่าย)
- Cunning Strike แปลงเป็น skill เลือกผล (ล้ม, ถอย, ทำให้มึน) แลกกับดาเมจที่ลดลง แทนการใช้ mana
- เดินเพิ่ม/ถอยหลังโจมตี (Cunning Action) ทำเป็น skill ราคาถูกให้เล่นแนว hit-and-run บนแผนที่
