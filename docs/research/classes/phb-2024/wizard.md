# Wizard (พ่อมด/นักเวทศึกษา)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
Wizard คือนักวิชาการที่เรียนเวทมนตร์จากตำรา ใช้ Intelligence ร่ายเวท และเก็บเวทไว้ใน spellbook
มีรายชื่อเวทกว้างที่สุดในเกม เปลี่ยนเวทที่เตรียมได้ทุกวัน จึงแก้ปัญหาได้แทบทุกแบบถ้าเตรียมถูก แต่ตัวบางมาก

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: นักวิชาการหนอนหนังสือ, อาจารย์/ปราชญ์, นักล่าความรู้ในซากปรักหักพัง, ที่ปรึกษาราชสำนัก, คนกระหายอำนาจ
- แรงจูงใจ: ค้นหาเวทที่สาบสูญจากอารยธรรมโบราณ, เข้าใจกฎของเวท, ชื่อเสียงทางวิชาการ, อำนาจ
- จุดอ่อน/ข้อขัดแย้งภายใน: หยิ่งในความรู้, ตัวบางต้องพึ่งเพื่อน, spellbook หาย = เสียพลังไปมาก, ความอยากรู้อาจพาไปหาเวทต้องห้าม
- ไอเดียตัวละคร:
  - บรรณารักษ์ที่แอบเรียนเวทจากหนังสือต้องห้ามในห้องใต้ดินของหอสมุด
  - นักศึกษาที่ถูกไล่ออกจากสถาบันเวท และออกเดินทางเพื่อพิสูจน์ทฤษฎีของตัวเอง
  - นักโบราณคดีที่ตามหาตำราของอารยธรรมที่ล่มสลาย
  - ที่ปรึกษาเจ้าเมืองที่ใช้ความรู้เวทวางแผนการเมืองมากกว่าการรบ

## บทบาทในปาร์ตี้
control / damage (area) / utility (ritual, ความรู้) · ความยาก: ยาก (เวทเยอะต้องเลือกเตรียมทุกวัน, HP ต่ำ, ต้องจัดตำแหน่งดี)

|---|---|

## Subclass ใน PHB 2024 (ชื่อเท่านั้น)
Abjurer · Diviner · Evoker · Illusionist

## แนวคิดสำหรับแอปเรา
- HP ต่ำสุด, mana สูง, str/end ต่ำ; เป็นสาย control/area เน้นวางตำแหน่งบน grid ให้ห่างแนวหน้า
- skill ที่ใช้ mana หลากหลายที่สุด แต่เลือกพกได้จำกัด (ใกล้กับ "prepared spells"): ให้ DM/ผู้เล่นเลือก 3 custom skill ก่อนเซสชัน
- Arcane Recovery แปลงเป็น "พักแล้วคืน mana บางส่วน 1 ครั้ง/เซสชัน"
