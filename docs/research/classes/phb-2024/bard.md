# Bard (นักกวีเวทดนตรี)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
นักแสดงที่ใช้เพลง คำพูด และเวทมนตร์ (full caster ด้วย Charisma) ช่วยเพื่อนและกวนศัตรู
เล่นแบบแจก Bardic Inspiration ให้เพื่อนเติมลูกเต๋า ร่ายเวทช่วย/คุมสนาม และเก่ง skill รอบด้าน

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: นักร้องพเนจร, นักเล่าเรื่อง/นักประวัติศาสตร์, นักต้มตุ๋นปากหวาน, นักแสดงในราชสำนัก
- แรงจูงใจ: ตามหาเรื่องราวที่ยิ่งใหญ่, อยากมีชื่อเสียง, เก็บความรู้ที่หายไป, ใช้คำพูดเปลี่ยนโลก
- จุดอ่อน/ข้อขัดแย้งภายใน: ชอบเป็นจุดสนใจ, พูดเกินจริงจนคนไม่เชื่อ, เสพติดคำชม, ซ่อนตัวตนจริงไว้หลังบทบาท
- ไอเดียตัวละคร:
  - นักดนตรีโรงเตี๊ยมที่จำเพลงต้องห้ามของอาณาจักรเก่าได้ทั้งหมด
  - นักเขียนบทละครที่ออกเดินทางหาตอนจบให้เรื่องที่เขียนไม่เสร็จ
  - นักเจรจาปากหวานที่เคยหลอกขุนนางมาแล้วครึ่งเมือง
  - นักเต้นคณะละครเร่ที่ใช้จังหวะเท้าแทนบทสวด

## บทบาทในปาร์ตี้
support + face + control (utility ด้วย skill รอบด้าน) · ความยาก: **กลาง**

## แนวคิดสำหรับแอปเรา
- stat: mana สูง, agi กลาง, HP/str/end ต่ำ
- skill ที่ใช้ mana = "เพลงปลุกใจ" (เพื่อน 1 คนบวกทอยครั้งถัดไป) และ "เพลงกล่อม/สะกด" (ศัตรูเสียตาหรือทอยแย่ลง) + ฮีลเล็กน้อย
- เหมาะเป็นสาย support/คุยกับ NPC; DM ให้โบนัสตอนเจรจาได้
