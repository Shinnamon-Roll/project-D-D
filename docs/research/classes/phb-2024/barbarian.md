# Barbarian (นักรบเถื่อน)

> แพค: Player's Handbook (2024) · base class เท่านั้น · สรุปด้วยคำของเราเอง ไม่ใช่เนื้อหาในแอป

## ภาพรวม
นักรบสายประชิดที่พลังมาจากความโกรธดิบ ๆ เปิด Rage แล้วตีแรงขึ้น ทนดาเมจกายภาพได้ครึ่งเดียว เล่นง่าย: วิ่งเข้าหาศัตรู เปิด Rage แล้วฟัน
จุดเด่นคือ HP สูงที่สุดในเกม (d12) และแลกการป้องกันเพื่อโจมตีแรงขึ้นได้ (Reckless Attack)

## นิสัยและบุคลิก (roleplay)
- archetype ที่พบบ่อย: คนจากชนเผ่า/ป่าเขา, นักสู้ข้างถนน, ทหารที่ผ่านสงครามมาหนัก, ผู้ที่มีวิญญาณสัตว์คุ้มครอง
- แรงจูงใจ: ปกป้องเผ่า/พวกพ้อง, ล้างแค้น, พิสูจน์ความแข็งแกร่ง, หนีจากอดีต
- จุดอ่อน/ข้อขัดแย้งภายใน: คุมอารมณ์ไม่ได้, กลัวว่าตัวเองจะทำร้ายคนที่รัก, ไม่ไว้ใจเมืองและเวทมนตร์, ตัดสินใจด้วยหัวใจก่อนสมอง
- ไอเดียตัวละคร:
  - ช่างตีเหล็กเงียบขรึมที่ระเบิดอารมณ์ทุกครั้งที่เห็นคนอ่อนแอถูกรังแก
  - ลูกหลานเผ่าที่ถูกเนรเทศ ออกเดินทางเพื่อหาทางกลับบ้าน
  - อดีตนักมวยสังเวียนใต้ดินที่อยากเลิกสู้เพื่อเงิน แต่หนีไม่พ้น
  - นักล่าในป่าหนาวที่เชื่อว่าวิญญาณหมาป่าคอยกระซิบเตือนภัย

## บทบาทในปาร์ตี้
tank + damage (melee) · ความยาก: **ง่าย**

## ข้อมูลหลัก
| | |
|---|---|
| Hit Die | d12 |
| HP เลเวล 1 / ต่อเลเวล | 12 + CON mod / 1d12 (หรือ 7) + CON mod |
| Primary ability | Strength |
| Saving throws | Strength, Constitution |
| Armor / Weapons | Light, Medium armor, Shields / Simple + Martial weapons |
| Tools / Skills | ไม่มี tool / เลือก 2 จาก Animal Handling, Athletics, Intimidation, Nature, Perception, Survival |
| Starting equipment | (A) Greataxe, Handaxe 4 อัน, Explorer's Pack, 15 GP หรือ (B) 75 GP |
| Spellcasting | ไม่มี (ร่ายเวท/Concentration ไม่ได้ระหว่าง Rage) |
| Resource หลัก | Rages (2 → 6 ครั้ง/Long Rest, Short Rest คืน 1 ครั้ง) + Rage Damage (+2 → +4) |

## Feature ตามเลเวล (1-20)
| Level | Feature | สรุปสั้น |
|---|---|---|
| 1 | Rage | bonus action เข้าโหมดคลั่ง: ต้านดาเมจ bludgeoning/piercing/slashing, ดาเมจ STR เพิ่ม, advantage STR check/save; ใส่ heavy armor ไม่ได้ |
| 1 | Unarmored Defense | ไม่ใส่เกราะ AC = 10 + DEX + CON (ถือโล่ได้) |
| 1 | Weapon Mastery | ใช้ mastery property ของอาวุธประชิดได้ 2 ชนิด (เพิ่มเป็น 3 ที่เลเวล 4, 4 ที่เลเวล 10) สลับได้หลัง Long Rest |

## แนวคิดสำหรับแอปเรา
- stat: HP สูงสุดในปาร์ตี้ + str/end สูง, agi กลาง, mana ต่ำ (ไม่มีเวท)
- skill ที่ใช้ mana = "คลั่ง" (บัฟหลายตา: ลดดาเมจที่โดน + ดาเมจเพิ่ม) และ "ฟันสุดแรง" (ดาเมจ + ผลักศัตรู/ทำให้ช้า)
- ทางเลือกเสี่ยงแลกได้ (แบบ Reckless Attack): ตีแม่นขึ้นแต่ศัตรูตีเราง่ายขึ้นด้วย เหมาะกับผู้เล่นมือใหม่
